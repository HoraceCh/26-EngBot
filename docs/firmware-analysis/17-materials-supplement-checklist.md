# 来源与合规资料补充清单

> 建立日期：2026-07-23  
> 配套核验清单：[16-license-verification-checklist.md](16-license-verification-checklist.md)  
> 说明：本文只负责收集、整理和索引客观资料，不直接作出“允许发布”的法律或合规结论。

## 1. 资料管理规则

每份资料至少记录：

- 稳定证据编号。
- 资料名称和对应仓库路径。
- 来源主体、URL 或受控保管位置。
- 版本、commit/tag、获取日期。
- SHA-256 或其他稳定校验值。
- 收集人、复核人和复核日期。
- 适用发布范围。
- 是否包含敏感信息。

书面授权、合同等敏感材料可以存放在受控系统中，不必提交到公开仓库；但公开或内部台账必须保存不含敏感内容的证据编号、保管位置、适用文件/版本和审核状态。

优先级：

- **R0——发布必需：** 缺失时无法解除发布阻断。
- **R1——条件证明：** 用于证明已满足第三方许可条件。
- **R2——长期追溯：** 用于维护、升级和后续审计。

## 6. 证据索引模板

| 字段 | 填写内容 |
| --- | --- |
| 证据编号 | `AUTH-*`、`SRC-*`、`VENDOR-*`、`MOD-*`、`CAD-*`、`DOC-*`、`BUILD-*` 或 `REL-*` |
| 对应任务 | `MAT-*` 与 `LIC-*` 编号 |
| 名称 | 资料或授权名称 |
| 对应路径 | 仓库文件、目录或发布包路径 |
| 来源/保管位置 | 权威 URL 或受控系统编号 |
| 版本与日期 | tag/commit/版本、获取或签署日期 |
| 校验值 | SHA-256；纸质/邮件授权记录稳定编号 |
| 收集人 | 姓名、日期 |
| 复核人 | 姓名、日期 |
| 适用范围 | 完整仓库、固件源码、固件二进制、机械资料 |
| 保密级别 | 公开、内部、受限 |
| 备注 | 修改、例外、到期时间等 |

## 7. 资料齐全判定

资料包只有满足以下条件才可提交许可证审核：

1. 所有适用的 R0 资料任务已完成。
2. 证据编号、路径、版本和 hash 能互相对应。
3. 上游 URL 或受控保管位置可以由第二人访问复核。
4. 逐文件 SBOM 覆盖目标发布包全部文件。
5. 固件产物、CAD、PDF 和静态库均有独立来源记录。
6. 不以口头说明、文件名或仓库公开状态代替授权证据。

资料齐全只表示“具备审核输入”，最终是否允许发布仍以
[许可证与授权人工核验清单](16-license-verification-checklist.md) 的结论为准。
